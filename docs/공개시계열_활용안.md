# 배터리아카데미 v12.2 — 공개 시계열 3종 활용안

작성 기준: 2026-10-28. 검토 대상은 업로드된 v12.2 프로그램·브리핑·근거 보고서와 21장 발표자료, 공개 Streamlit 화면이다.

## 1. 선정 결과와 사용 범위

**원출처 2개에서 3종을 선정했다.** 건조의 시간–품질 관계, 화성 단축 후의 수명, 조기 전압검사의 관찰시간을 각각 확인한다. 세 그래프를 서로 독립적인 논문 3건으로 세지 않는다.

| 데이터 | 시간축·관측량 | 이번에 확인할 핵심 | PPT·프로그램·후속 실험에 공통으로 쓰는 방법 |
|---|---|---|---|
| ① 건조 중 NMP 잔량 | 경과 초(s) × kg NMP/kg 건조 전극. 대표 곡선 18점 | 후반 감률 구간이 있어 용매량 감소를 건조시간 감소로 그대로 치환하기 어려움 | B1의 65 wt%·1.2배 속도 검증 설계, 잔류 NMP·접착·크랙 관문 설명 |
| ② 화성 방식별 후속 용량 | 사이클 번호 × 각 셀 cycle 2 대비 C/3 진단 용량. 39셀×5회 | 시간 단축안의 품질 검증에 후속 수명 자료가 필요한 이유 | FOR-FAST 검토 근거, RT/45°C 조건별 비교, C사 20 h/16 h 대조 실험 설계 |
| ③ 화성 후 6 h 전압 변화 | 휴지시간(h) × 시작 대비 전압 하락(mV). 39셀×7시점 | 전압 완화와 결함 신호를 구분하고 검사시간·채널 점유를 따로 계산해야 함 | AGE-EARLY 섀도 모드 설계, 화성 추가 점유 ≤40분 확인, 초기 신호–14일 판정 연결 |

①은 **논문 그림을 수치화한 근사값**, ②·③은 **저자가 공개한 실험 가공 데이터**다. 임의로 만든 가상 공장 시계열은 없다. ②의 사이클 번호는 시간 순서 지표이며 달력 일수로 환산하지 않았다.

## 2. 그래프별 해석과 발표 멘트

### ① 건조: 후반 용매 제거와 품질을 같이 보기

파일: `plots/01_drying.png`, `plots/01_drying.svg`.

Bryntesen 등의 실험은 NMC111/카본블랙/PVDF 양극과 NMP 용매를 사용한 실험실 열풍건조다. Fig.4의 대표 조건은 100°C, 공기속도 1 m/s이다. 그림의 회색 실험점 18개를 추출했다. 별도 패널에는 Table 5의 네 조건에서 정률 건조속도와 캘린더 전 크랙 면적을 옮겼다. 두 패널은 서로 다른 종류의 관측이며 동일 시점끼리 대응시키지 않는다.[S1]

**읽을 부분:** NMP 제거가 후반부에 느려진다. 건조속도가 큰 조건에서는 표면 구조도 달라졌다. 따라서 고형분 증가로 계산한 용매 감소량만으로 출구 품질이나 1.2배 코팅속도를 승인하면 안 된다. 크랙 증가가 모든 전기화학 성능 저하를 의미하는 것은 아니므로 접착과 성능도 함께 확인한다.[S1]

**발표용 멘트 — 기존 PPT 6번 다음 권장**

> “고형분 증가에 따른 용매 부하 감소는 질량수지로 계산할 수 있습니다. 다만 실제 건조는 후반에 느려지므로, 건조시간도 같은 비율로 줄어든다고 단정하지 않았습니다. 그래서 60·65 wt%와 기준·1.2배 속도를 조합한 파일럿에서 잔류 NMP, 접착, 크랙을 동시에 확인하는 관문을 두었습니다.”

**프로그램 활용:** ‘PFMEA와 근거 → 공개 시계열 → ①’에서 곡선을 보여준 뒤 B1의 건조 속도 관문을 설명한다. DRY-HSC의 검증 설계에 연결하고 DRY-RAD의 NIR 효과 수치에는 직접 산입하지 않는다. 이 자료는 60→65 wt% 비교나 NIR 에너지 실험이 아니다.

**현장에서 추가할 값:** 같은 건조 도포량·최종 전극 밀도 조건에서 시간/위치별 잔류 NMP, 전극 온도, 구간 풍량, 출구 접착·크랙, 처리면적당 전력(kWh/m²). 코팅속도를 바꿀 때는 체류시간과 실제 처리면적을 함께 기록한다. 합격 잔류 NMP 기준은 C사 규격으로 정해야 하며 이 논문에서 임의로 가져오지 않는다.

### ② 화성: 속도와 후속 수명을 같은 셀로 연결

파일: `plots/02_formation_quality.png`, `plots/02_formation_quality.svg`.

Weng 등의 NMC111/흑연 2.36 Ah 파우치 연구에서 저자 공개 CSV를 사용했다. 제작 40셀 중 탭 용접 문제로 제외된 9번 셀을 제외한 39셀이다. 화성은 실온에서 수행하고 후속 사이클 시험을 RT와 45°C로 나눈다. 모든 셀에 공통으로 존재하는 cycle 2·55·158·261·364의 C/3 진단 용량을 사용했다.[S2, D1]

각 셀의 cycle 2 용량을 100%로 정규화한 뒤 군별 중앙값과 25–75% 범위(IQR)를 계산했다. PNG·프로그램에는 IQR을, PPT의 편집 가능한 차트에는 중앙값을 표시했다. IQR은 신뢰구간이 아니다.

| 후속 시험 온도 | 기준 화성 셀 수 | 고속 화성 셀 수 | cycle 364 기준 화성 중앙값 | cycle 364 고속 화성 중앙값 |
|---|---:|---:|---:|---:|
| 실온 RT | 10 | 10 | 79.0% | 91.6% |
| 45°C | 9 | 10 | 78.1% | 87.6% |

위 수치는 **이번에 저자 CSV로 계산한 기술통계**다. 논문의 표를 그대로 인용한 값이나 C사 수명 예측값이 아니다. 동일한 39셀을 끝까지 사용하며 결측 보간·수명 외삽을 하지 않았다.[D1]

**발표용 멘트 — 기존 PPT 7번 다음 권장**

> “고속 화성을 검토하는 이유는 단축 시간뿐 아니라, 이후 수명을 함께 관찰한 공개 실험이 있기 때문입니다. 이 셀 설계에서는 고속군의 후속 용량 유지가 양호했습니다. 하지만 C사 셀과 프로토콜이 다르므로, 20시간·16시간 대조군에서 수명·가스·저항을 따로 검증하겠습니다.”

**프로그램 활용:** ‘②’를 선택해 RT와 45°C를 전환하고 ‘개별 셀 곡선 표시’를 켜 군 내부 편차를 확인한다. FOR-FAST의 품질 검증 필요성을 설명하는 자료이며 관문을 자동 완료하지 않는다.

**시간 수치의 구분:** Weng 연구의 고속 14 h/기준 56 h는 진단 단계를 제외한 시간이다. C사의 20→16 h 목표와 같은 프로토콜로 취급하지 않는다. 6 h 휴지 등 진단·이송·재검·탈기 시간은 실제 설비 점유 여부에 따라 별도로 계산해야 한다.[S2, Fig.S1 및 Formation protocols 절]

### ③ 에이징 검증: 초기 전압 하락을 곧바로 불량으로 보지 않기

파일: `plots/03_rest_voltage.png`, `plots/03_rest_voltage.svg`.

②와 같은 39셀의 실온 6 h 휴지 데이터를 사용한다. 저자가 평활한 전압에서 계산한 1 h 간격 특징량이며 초 단위 원시 파형은 아니다. 0 h는 시작 전압 대비 하락량을 0으로 정의한 기준점이다. 원자료의 V를 1,000배하여 mV로 표시했다.[D1, C1]

6 h 하락량 중앙값은 기준 화성 20.39 mV(19셀), 고속 화성 22.53 mV(20셀)이다. 고속군은 전압 하락량이 더 크지만 ②에서 후속 용량 유지도 양호했다. 따라서 이 자료만으로 ‘전압이 더 많이 떨어지면 불량’이라는 단일 임계값을 정할 수 없다. 내부단락 정답 라벨이 없어 결함 검출 민감도도 계산할 수 없다.[D1]

**발표용 멘트 — 기존 PPT 20번 섀도 모드 다음 권장**

> “초기 전압 하락에는 완화가 섞여 있습니다. 이 곡선을 곧바로 불량 판정선으로 쓰지 않고, 기존 14일 판정을 유지하면서 같은 셀의 조기 전압·온도와 최종 결함 판정을 연결하겠습니다. 6시간 관찰을 화성 채널에서 추가하면 40분 예산을 넘으므로 측정 경로도 함께 검토합니다.”

**프로그램 활용:** ‘③’의 왼쪽은 누적 전압 하락, 오른쪽은 셀별 연속 관측점 차이의 중앙값을 보여준다. 40분 표시는 팀의 시간 예산 표시이며 40분 시점의 측정값이나 검출 성능을 추정한 선이 아니다. 별도 측정기를 쓸 경우에도 병렬 채널 수, 이송, 안정화, 재검, 비용이 충족되는지 확인한다.

**현장에서 추가할 값:** 셀 ID, 화성 프로토콜, SOC, 시간, 전압, 셀/주변 온도, 측정 장비·분해능, 14일 기존 판정, 결함 유형, 재검·장기 추적 결과. 이 연구의 39셀을 팀의 독립 결함 양성 299개 요건 대신 세면 안 된다. 14일 OCV 판정 자체도 모든 잠재 결함을 완전히 포착한다는 전제가 아니므로 불일치 셀은 추가 검사·장기 추적으로 확인한다.

## 3. 기존 분석에 반영한 방식

새 코드는 기존 3개 탭 중 **‘PFMEA와 근거’ 상단에 시계열 선택·온도 필터·개별 셀 표시·PNG/CSV 다운로드·출처 보기**를 추가한다. 기존 근거 데이터베이스와 계산 엔진에 값을 덮어쓰지 않는다.

공개자료로 이번에 설명이 강화된 것은 ‘왜 이 검증이 필요한가’이다. 다음 v12.2 결과와 미확인 조건은 그대로 유지한다.

| 기존 항목 | 유지한 상태 |
|---|---|
| 공식 D2/B1 대표 원단위 절감 | 34.98% ≈ 35.0%: 기존 가정·근거 모델 결과 |
| 공장 총전력 | 78.03 pt, 목표 84 pt 대비 여유 5.97 pt |
| 승인 슬롯 증설 전 처리능력 | 1.056배: 에이징 병목 미완결 |
| 승인 슬롯 증가 | +13.68% 등 기존 현장 조건 확인 필요 |
| 화성 추가 채널 점유 | ≤40분 조건 유지 |
| 품질 관문 | 41개 중 안전 15개: 공개 그래프만으로 승인하지 않음 |
| 고정부하 f | 새 실측 검증 없음. f=0에서 29.57%로 미달하는 기존 민감도 유지 |

건조·드라이룸의 **계통 전력과 생산량의 동시 시계열**은 다음 현장 데이터 수집 1순위다. 이번 자료로 고정부하 f나 NIR 실전력 절감률을 맞췄다고 발표하지 않는다. 공개 HVAC 시간별 모델 데이터 후보(DOI 10.17632/hxc4k97vmp.1)는 수치 파일을 확보하지 못해 그래프에서 제외했다.[S3]

## 4. 발표와 화면 시연 순서

1. **결론 화면:** 기존 35.0%를 보여주고 ‘검증 조건이 붙은 모델 결과’임을 먼저 말한다.
2. **① 건조:** 실제 곡선이 직선이 아님을 짚고 출구 품질·속도 관문으로 연결한다.
3. **② 수명:** RT/45°C 비교 → 개별 셀 표시 → C사 대조 실험 필요성을 설명한다.
4. **③ 전압:** 완화와 불량 검출을 구분 → 6 h와 40분의 설비 점유 차이 → 14일 병행검증을 설명한다.
5. **전환 조건으로 복귀:** 전력, 화성, 에이징 승인 슬롯, 품질 관문을 모두 확인해야 전체 목표를 승인할 수 있음을 정리한다.

발표 시간이 짧으면 보충 3장은 질의응답용으로 두고 본문에서는 각 곡선의 핵심 한 문장만 설명해도 된다. 보충 PPT는 원본 21장에 합친 파일이 아니라 **삽입용 3장**이다. 삽입 위치의 번호는 기존 원본 기준이다. 모든 차트는 데이터가 포함된 편집 가능한 PowerPoint 차트이며 출처와 발표 멘트는 각 장의 발표자 노트에 있다.

## 5. 프로그램 반영 방법

**이 결과물은 로컬 반영본이다. 공개 Streamlit 주소에는 아직 배포하지 않았다.**

전체 ZIP에는 `program/` 실행본과 기존 저장소에 적용하는 `apply_to_existing.py`를 넣었다. 실행본은 업로드 v12.2의 계산 파일을 유지하고, 공개 저장소에서 확인한 2026-10-28 `app.py` 화면에 새 영역을 추가한 것이다.

기존 GitHub 저장소의 로컬 사본에 적용할 때:

```bash
python apply_to_existing.py --project /path/to/battery-academy-p4
```

스크립트는 `app.py`의 `with tab3:` 아래에 호출 두 줄을 넣고 새 모듈·데이터·폰트를 복사한다. 최초 수정 전 `app.py.before_timeseries`로 백업하며 반복 실행 시 호출을 중복 추가하지 않는다. 기존 `core.py`, `candidates.py`, `data/kb/`, `outputs/results.json`은 건드리지 않는다. 이후 변경 파일을 기존 저장소에 반영하고 Streamlit 배포를 갱신해야 주소의 화면이 바뀐다.

전체 실행본으로 확인할 때:

```bash
cd program
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

그래프를 다시 뽑을 때:

```bash
python timeseries_evidence.py
```

`program/timeseries_outputs/`에 PNG·SVG가 생성된다. `program/tools/rebuild_timeseries_data.py`는 함께 제공한 출처 CSV와 그림 좌표로 파생 CSV를 재생성한다. 스크립트에 입력 출처와 단위 변환을 남겼다. 사용 폰트는 함께 제공한 NanumGothic이며 PPT 편집 시 해당 폰트를 설치하면 표시를 맞출 수 있다.

## 7. 검증 기록

기존 UI·v12.2 판정 회귀검사 14개가 통과했다. 추가로 세 데이터의 원자료 변환·셀 수·공통 시점, 새 화면의 세 선택지·온도 필터·개별 셀 표시, 기존 엔진 파일과 결과 JSON 보존을 확인했다. 상세 결과는 ZIP의 `validation/`에 있다.

PPT는 3장·네이티브 차트 4개·내장 차트 데이터의 구조 및 재가져오기 검사를 통과했고 렌더링으로 한글과 배치를 확인했다. 사용자 PC의 PowerPoint에서 직접 연 검사는 수행하지 않았다.
