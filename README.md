# 배터리셀 공장 병목공정 개선안 - 근거 기반 판정 프로그램

**2026 배터리아카데미 · 문제 4**
배터리셀 공장의 병목공정(화성·에이징, 전극건조·드라이룸)에서 시간·에너지 비용을 줄이기 위한 공정 혁신방안

C사 공장(10 → 12 GWh, 전력 원단위 -30%)의 개선안 후보를 **같은 기준선·같은 근거**로 계산해 비교한다. 결과가 **어떤 조건에서 깨지는지**까지 자동으로 판정한다.

> 🖥️ **프로그램 바로 실행 (웹): https://battery-academy-p4.streamlit.app**
> 📄 **결과 보고서 바로 보기: [outputs/evidence_report.pdf](outputs/evidence_report.pdf)** (1~17쪽 본문)
> 📊 모든 숫자의 원본: [outputs/results.json](outputs/results.json)

## 결론

**조건부 추천 B1 (양극 슬러리 고형분 60 → 65% + 복사(NIR) 건조)**
**전력 목표는 계산상 충족하고, 현장에서 확인할 조건이 4개 남아 있다.**

| 항목 | 값 |
|---|---|
| 전력 원단위 절감 | **35.0%** (목표 30%) |
| 12 GWh 총전력 | **78.03 pt** (현재 100, 목표 84 이하) · 여유 **+5.97 pt** |
| 절감 구성 | 공정 개조 27.64%p + 고정부하 희석 7.33%p |
| 연 전력비 | 현재보다 **연 200~260억 원 감소** (생산 20% 증가 후에도 총액 감소) · 무개선 증산 대비 연 302~392억 원 회피 |
| 공장 처리능력 | 건조 1.238 · 화성 1.250 · 에이징 1.056배 → **남은 병목은 에이징 보관 공간 +13.68%** (공장 면적 최대 약 3.4%, 방재 승인 후 확보) |
| 확인 조건 | 건조 처리능력(실측 속도), 화성 추가 점유(40분 예산), 에이징 승인 슬롯, 품질·안전 관문 41건(안전 15) |

### 같은 조건에서 두 목표를 함께 판정
| 조건 | 전력 -30% | 생산능력 +20% | 종합 |
|---|---|---|---|
| 기본 설계 + 승인 슬롯 +13.68% | 35.0% 충족 | 1.200 충족 | 조건부 추천 |
| 같은 설계, 에이징 공간 미확보 | 31.0% 충족 | 1.056 미달 | 전력만 충족 |
| 문헌 효과 90% + 관리 전력 4 pt | 29.1% 미달 | 변화 없음 | 전력 미달 |
| 드라이룸 재생열이 가스·스팀 | 28.8% 미달 | 변화 없음 | 전력 미달 |

전체 8개 조건은 보고서 2쪽에 있다.

## 이 프로그램이 하는 일
1. **후보 비교 (A · B0 · B1 · B2 · C)**: 같은 기준선, 같은 근거, 같은 열원 가정으로 비교한다. 상태는 4가지로 구분한다(검증 완료 / 가정하 수치 충족 / 미확인 / 미달). 미확인은 통과로 치지 않는다.
2. **근거 데이터셋**: 근거 자료 62개, 정량 효과 49건, 고장모드(FMEA) 62건. 각 값에 원문 위치, 근거 등급, 적용 조건을 붙였다.
3. **설계 고정**: 서로 다른 기술 근거의 중앙값을 쓰지 않는다. 실제로 고른 설계의 근거만 쓴다.
   - 드라이룸 부분 국소화
   - Weng 2021 계열 고속 화성
   - NIR 건조
   - 기술군 중앙값(35.6%)과 비교한 결과는 보고서 17쪽에 있다.
4. **실패 경계·스트레스**: 다음 경우에 결론이 언제 바뀌는지 계산한다.
   - 문헌 효과 재현율과 관리 전력이 동시에 나빠질 때(α–P 영역)
   - 열원이 가스일 때
   - 고정부하 가정이 틀릴 때
   - 수율이 떨어질 때
5. **처리능력 통합**: 공장 처리능력 = min(건조, 화성, 에이징)으로 병목을 찾고, 연차별 생산비와 원단위를 함께 계산한다.
6. **로드맵·경제성**: 단기·중기·장기로 분류하고 검증 기준을 붙인다. 영향평가 매트릭스, 레버별 손익분기 투자비, 3년 간트, 에이징 섀도 모드(조기 선별) 계획도 낸다.
7. **자기 검증**:
   - 테스트 224개
   - 손계산 검산 35/35
   - results.json ↔ CSV ↔ PDF 숫자 자동 일치 검사(15항목, 실패 시 종료코드 1)

## 실행 방법
```powershell
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python run.py --run-tests          # 보고서·CSV·results.json 생성 + 테스트 + 숫자 일치 검사
.\.venv\Scripts\python tools\verify_v11.py         # 손계산 검산 (35/35 일치)
.\.venv\Scripts\streamlit run app.py               # 화면(localhost:8501)
```

## 한계
- 문헌값과 공개 자료로 만든 **조건부 계산 도구**다. C사 실측값(열원, 실제 고형분, 슬롯 사용률, 불량률), 설비 견적, 파일럿 결과는 없다.
- 그래서 결론은 '충족 확정'이 아니라 '계산상 충족 + 현장 확인 조건'이다.
- 근거가 없는 레버는 효과를 0으로 계산했다. 효과가 없다는 뜻이 아니라 1년차 실측 후 편입할 후보라는 뜻이다.
